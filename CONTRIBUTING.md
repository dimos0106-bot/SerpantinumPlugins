# Contributing

Thanks for helping improve Serpantinum Plugins.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Name the plugin and version involved.
- Include your Serpantinum setup and clear steps to reproduce the problem.
- Attach screenshots or relevant logs when they help explain the issue.
- Remove private paths, access tokens, keys, and other sensitive data before posting.

## Proposing a feature

Explain the problem the feature would solve, how it should fit into Serpantinum, and any user-facing settings it may need.

## Submitting changes

- Keep each plugin as self-contained as possible.
- Update the plugin's README when behaviour, dependencies, installation, or compatibility changes.
- Do not claim compatibility with a Serpantinum version unless it has been checked.
- Keep the root README and screenshots consistent with the current project.
- Test changes in a real Serpantinum environment before describing them as working.

## Licensing

No repository-wide licence has been selected yet. Please do not assume contributions can be redistributed under an unspecified licence.
